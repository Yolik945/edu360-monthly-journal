## 动态网站本地运行

需要 Node.js 22.13 或以上版本，以及 pnpm。在 `动态夏季刊` 目录执行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

生产构建：

```sh
pnpm build
```

网站采用 React、Vinext 和 Vite。主要内容位于 `app/journal-data.json`；主视觉位于 `app/page.tsx`；展开详情位于 `app/story-content.tsx`；样式位于 `app/globals.css`；照片位于 `public/photos`。

现有在线站点由 Sites 托管。此仓库用于完整归档和后续维护，向 GitHub 推送内容不会自动更新在线站点。

## 制作与留存

原稿 109 张照片加 1 张补充照片，共 110 张。完整原始照片保存在 `制作文件/photos`，网站使用的优化副本保存在 `动态夏季刊/public/photos`。

印刷版制作脚本位于 `制作文件/build_magazine.py`、`制作文件/v2/build_print.py`，对应导出脚本使用 Playwright 和 Sharp；部分脚本保留了原制作电脑的运行库绝对路径，在其他电脑重建时需按环境调整。已导出的成品不依赖这些运行库。

仓库不收录可重新安装的依赖、编译缓存、临时发布包、重复审阅截图和补图前备份；最终成品、原稿、原图、内容数据和制作源码均已收录。
